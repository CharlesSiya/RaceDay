# RaceDay

RaceDay is a web-based event management system designed
for the South African road running, walking and cycling
community.

 Part 1

Part 1 focuses on system planning and database design.

The following planning documents are included:

- Entity Relationship Diagram
- REST API Endpoint Plan
- SQL Server Database Script

## User Roles

### Organiser

An Organiser can:

- Create events
- Edit events
- Delete events
- Manage event categories
- Capture participant results
- View event enrolments

### Participant

A Participant can:

- Create an account
- Browse events
- Enter an event by selecting a category
- View their own enrolments
- Track personal results

## Database

The RaceDay database is designed for SQL Server.

The database contains the following entities:

- Users
- Events
- Categories
- Routes
- Enrollments
- Results
